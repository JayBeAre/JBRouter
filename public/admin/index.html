Role Mapping

The most specific matching keyword selects the pool for an incoming model name; otherwise the default pool is used.

Pools

Each pool is an ordered fallback list of provider + model entries. If every entry in a pool fails, its optional "fall back to pool" setting lets the router continue into another pool.
